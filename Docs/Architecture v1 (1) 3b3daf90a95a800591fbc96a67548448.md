# Architecture v1 (1)

**arXiv + HuggingFace Daily Papers + AI Lab Blog + X + 중국 AI Lab + US Federal Register**를 자동 수집하고, **Rust + Python + Qdrant + Neo4j + LLM Agent**로 분석
