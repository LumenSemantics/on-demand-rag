## 프로젝트 규모

이 설계를 모두 구현하면 대략 다음 규모가 예상됩니다.

- 약 60~80개의 Source Connector
- 약 80~120개의 Python 모듈
- 약 40~60개의 Rust 모듈
- 약 150~250개의 API 엔드포인트
- 약 250~400개의 테스트
- 총 코드 규모 **5만~10만 줄**

이는 단순 예제가 아니라 **실제 서비스 가능한 AI Research Intelligence Platform** 수준입니다.

### 제안하는 진행 방식

이 프로젝트는 한 번의 답변으로 모두 작성하기보다, 실제 GitHub 저장소를 개발하듯 **시리즈 형태**로 진행하는 것이 가장 현실적입니다.
